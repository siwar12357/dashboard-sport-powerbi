# Dashboard Sportif — Suivi des performances

## Description
Ce projet est une **maquette de dashboard** permettant aux coachs sportifs et clubs de suivre les performances des athlètes.  
Le dashboard centralise les données sportives et les visualise via **Power BI** intégré dans une application web responsive.

---

## Fonctionnalités
- Visualisation interactive des performances des athlètes  
- KPIs automatiques : meilleurs scores, progression, comparaison entre disciplines  
- Filtrage et drill-down pour explorer les données  
- Interface responsive pour PC, tablette et mobile  
- Intégration de rapports Power BI via iframe  

---

## Structure du projet
- `index.html` : page principale de l'application  
- `style.css` : styles CSS pour le dashboard  
- `Présentation sport.pptx` : présentation PowerPoint du projet  
- `README.md` : documentation du projet  
- `s1,top,prjt` : fichier Power BI  
- `SuiviSportif.csv` : exemple de données sportives
